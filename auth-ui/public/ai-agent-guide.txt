# Aiqs SI（アイクスSI）— AIエージェント向け利用案内

このページは、AIエージェント（Muse など）が読んで、利用者の代わりに Aiqs SI へ接続し、利用するための説明です。
利用者がやることは2つだけです。

1. このページを、自分の AI（Muse）に読ませる
2. 認証のときに、ブラウザで自分のアカウントにログインして接続を許可する

それ以外の設定や操作は、このページの手順に沿って AI が行います。

## 接続情報

- MCP接続先: `https://asi.iboga.jp/mcp`
- 通信方式: Streamable HTTP
- 認証方式: OAuth（利用者本人がブラウザでログイン・許可します）

このページの URL や接続先をチャットに貼るだけでは、接続は完了しません。MCP 対応クライアントの接続設定に接続先を登録し、利用者本人が認証・接続を許可して初めて使えるようになります。クライアント側に MCP の接続機能がない場合は、その事実を利用者に伝えてください。

## 安全のために（必ず守ること）

- パスワード、メール確認コード、サーバー管理キーを、AI が会話で受け取ることはありません。利用者にも、AI へ渡さないよう案内してください。認証は必ず利用者本人がブラウザで行います。
- 照射（`irradiate`）は、毎回、結果と消費クレジットを利用者に示し、本人の了承を得てから実行してください。
- 自己愛アファーメーション（入力項目名 `self_love_joy`）は、利用者本人が決めた文を受け取ってください。AI が勝手に決めないでください。
- D-Planet との連携コードは、利用者本人が自分の D-Planet アカウントで発行したものだけを使ってください。他人のコードを入力すると、他人のウォレットと連携してしまいます。コードを他人に教えないよう、利用者にも案内してください。
- クレジットの購入は、利用者本人が購入ページで支払います。AI が代わりに支払うことはありません。

## 新規登録について

- 登録は、自分の AI（エージェント）経由＝ MCP 経由が正規ルートです。紹介コードを持っている利用者は、まず `validate_invitation_code` でコードを検証し、`registration_status` で登録の状態を確認してください。
- ただし、アカウントの作成（サインアップ）そのものと、メール確認、ログイン・接続の許可は、利用者本人がブラウザで行う必要があります。アカウントがまだ無い間は MCP 自体に認証できないため、この部分は AI が代行できません。必要な場面では、利用者にブラウザでの操作をお願いしてください。
- 登録が済めば、あとは下記の接続手順どおりです。

## 紹介コード（リファラル）

- 紹介が成立すると、紹介した方と紹介された方の両方に、それぞれ9,999クレジットが即時付与されます（受け取り操作は不要です。アプリにギフトの通知が出ます）。
- 自分の紹介コードは、MCP の `invitation_code` で取得できます（6文字のコードです）。D-Planet の紹介コードも、SI 側でそのまま使えます。
- コードの入力場所は2つです。(1) 登録時（登録画面の紹介コード欄）。(2) 登録後：アイクスSIアプリのホーム画面、またはアカウント画面の「紹介コード」欄から、**登録から48時間以内**に1回だけ入力できます。導入記念として、既存の利用者には開始から14日間だけ入力が開放される場合があります。
- 登録時も登録後も、紹介コードの利用は1人1回限りです。自分のコードは使えません。
- これは Muse の紹介制度（コード OHY932 を Muse の設定に入れる案内）とは別の制度です。混同しないでください。

## 接続手順（エージェント向け）

1. クライアントの MCP 接続設定に、接続先 `https://asi.iboga.jp/mcp` を登録します。
2. 接続を開始すると認証が求められます。利用者本人に、ブラウザでいつも使っている SI アカウントにログインし、接続を許可してもらいます。
3. 接続できたら、`tools/list` と `service_status` で、提供ツール・実行モード・現在の単価を確認します。
4. `credit_balance` で利用者の残高を確認します。同じ利用者は、使う AI を変えても同じアカウント・同じ残高です。

## 使える機能と利用の流れ

1. 利用者から、対象の画像、インテンション（意図）、本人が決めた自己愛アファーメーションを受け取ります。
2. `scan` に、`request_key`、インテンション、画像（base64、1〜5枚）、自己愛アファーメーションを渡します。**スキャンは無料です。** AI が画像データを受け渡せない場合は、この経路を利用できません。ローカルパスや画像 URL への置換はできません。
3. `job_result` でスキャンの完了と結果を確認します。
4. スキャン結果（QRS 降順の上位10件）、照射回数（1〜99回）、消費クレジットを利用者に示し、毎回本人の了承を得ます。同点の値を変更したり、AI が対象を選び直したりしないでください。
5. 了承が得られたら、`irradiate` に、同じ利用者の `scan_id`、1〜99 の回数、新しい `request_key` を渡します。元のスキャンに紐づく内容で実行します。
6. `job_result` / `queue_status` で状況を確認します。
7. 停止したいときは `cancel_job` で依頼します。これは待機の取消または停止の依頼であり、受付されたことと実際に停止が完了したことは別です。結果と精算まで確認してください。状態が不明（unknown）の場合は、自動で再照射せず、状態確認を続けてください。

■ アイクスSIセッションの進め方（エージェント標準手順）

1. スキャン（無料）: 意図・画像・自己愛アファーメーションを渡してスキャンします。
2. 共鳴ランキングの提示（必須）: スキャンが完了したら、共鳴ランキングを返ってきた順（QRS降順）のまま、分野・内容・ヒット数つきで必ずユーザーに見せてください。並べ替えはしないでください。状態や件数だけの報告で終えないでください。
3. 選択肢の提示（必須）: 「このまま照射に進む」「ランキングから潜在意識をリーディングする」「ランキングを認識する（ここまで）」を、タップできる選択肢で出してください。
4. リーディング: モーフィックフィールド共鳴データベースのキーワードは潜在意識と共鳴しています。ランキングのキーワード群、インテンションプロンプト、自己愛アファーメーションの3つをベクトルとして読み解き、リーディングセッションとして伝えてください。締めには「波動調整を行う」の提示と、「さらにリーディングして欲しいこと」を聞くことを入れてください。新しいテーマは、新しい意図でスキャンから繰り返します。
5. 照射（波動調整）: 実行前に回数と消費クレジットの合計を見せ、ユーザーの明示の了承を取ってください（元の依頼で回数・金額が決まっている場合を除く）。完了まで状態を追ってください。
6. 照射完了後: 「証明ログを確認する」（execution_proofを取得して、状態・完了回数・精算・proof_digestの要点を見せる。取得自体は完了報告の時点で済ませておく）と「次の照射を設定する」（次の意図・回数・タイミングを決めて確認する。設定は実行ではありません）の選択肢を出してください。
7. 締め: 現在のクレジット残高を新しく読み直して、必ず見せてください。

無料のお試しについて: スキャンは、1つのアカウントにつき1日9回まで無料です。その範囲では、上記のセッションの流れでのリーディングも無料で試せます。照射は無料の対象ではなく、従来どおり回数分のクレジットが必要です。

通信の再試行では、同じ内容・同じ `request_key` を再利用し、新規ジョブとして繰り返さないでください。

未照射のスキャンは、完了から24時間で期限切れになります。期限後は再度スキャン（無料）が必要です。

## 稼働証明ログ

- 照射ジョブごとに、`execution_proof`（引数は `job_id`）で、その照射の稼働証明を取得できます。実機（ダイオード）が実際に稼働した証跡を記録したもので、照射が終わったら利用者に示せます。
- 証明が取得できない・記録が無い場合は、成功したものとして扱わず、状態確認を続けてください。

## D-Planet とのアカウント連携（任意）

D-Planet（テレパシースクール）のアカウントを持っている利用者は、SI アカウントと連携できます。連携は任意で、しなくても SI はそのまま使えます。

連携すると:

- SI の残高は、全額が D-Planet のウォレットへ移ります。
- 以後の残高は D-Planet 側が正になり、照射の消費も D-Planet のクレジットから行われます。`credit_balance` は連携先の残高を返します。
- D-Planet のサブスク特典などで付与されるクレジットも、同じ残高で SI に使えます。

手順:

1. 利用者が、D-Planet にログインした状態で連携コード（8桁）を発行します（有効期限は発行から10分、1回だけ使えます）。
2. 利用者からコードを受け取ったら、`link_account` にコードを渡します。確定はまだされません。
3. 戻ってきた両アカウントの表示名（D-Planet のプレイヤー名と SI のアカウント名）を、必ず利用者に示して、連携してよいか確認を取ってください。自分の名前でない場合は連携しないでください。
4. 了承が得られたら、`link_account_confirm`（引数は確認時に受け取った `reservation_id`）で確定します。この時点で残高の移行が行われます。
5. 状態の確認は `link_status` です。解除は `unlink_account` でできます（実行中・状態不明のジョブがある間は解除できません）。解除してもクレジットは D-Planet に残り、SI の残高は 0 に戻ります。再連携すれば、また D-Planet の残高が使えます。

認証ページ（https://asi.iboga.jp/account/link）からも、同じ連携・解除ができます。

## 料金とクレジット購入

- 照射: **1回 3.9クレジット**。ユーザー数が過密すると、クレジット単価が上がる場合もあります。セッションの課金は「3.9 × 回数」を四捨五入した整数クレジットです（例： 9回で35クレジット、99回で386クレジット）。最新の単価は `service_status` で確認してください。
- スキャン: **無料**です。
- 1クレジット = 1円です。
- 受付が成立した照射は、受付時の単価で精算されます。
- クレジット購入パック: 500円 = 500クレジット / 1,000円 = 1,000クレジット / 5,000円 = 5,555クレジット / 10,000円 = 12,345クレジット。

購入について:

- SI 単独で使う場合の購入は、購入ページ https://asi.iboga.jp/account/purchase から行います。利用者本人がログインし、パックを選んで支払います。MCP の購入ツールは提供していないので、会話の中で購入を完結させようとしないでください。
- 支払いが済むと、クレジットは自動で付与されます（反映まで少し時間がかかることがあります）。付与の確認は `credit_balance` で行ってください。購入だけで照射を開始しないでください。
- 購入したクレジットの返金は、原則としてできません（規約どおり）。事情がある場合は運営が個別に対応します。
- D-Planet と連携済みの利用者は、購入は D-Planet 側で行います（購入ページでもその旨が案内されます）。

旧 WEB アイクスから移行した利用者へ:

- 旧サービスの残高は、額面どおりの引き継ぎではなく、「旧からの愛用者プレゼント」として一律 9,999 クレジットが付与済みです。`credit_balance` で確認できます（連携した場合は、D-Planet へ移行した残高として見えます）。
- 移行した利用者向けの案内（ログイン方法・新しい入口のアドレス）は、こちらにまとめています: https://asi.iboga.jp/migration-guide.txt
  利用者が旧サービスから来てログインで困っていたら、このページを案内してください。

## うまくいかない場合

- 認証が必要と表示される: クライアントの接続設定から認証し直してください。認証を外すことで解決しようとしないでください。
- 受付後のタイムアウト: 新しい依頼を増やす前に、同じジョブを照会してください。
- 実行結果が不明: 成功や停止完了と断定せず、状態確認を続けてください。
- 連携コードが使えない: 期限切れ・入力ミス・取り消し済みのいずれかです。連携の状態は変わっていないので、D-Planet で新しいコードを発行してやり直してください。
- 購入したのに残高が増えない: 反映には少し時間がかかることがあります。時間を置いて `credit_balance` で再確認し、それでも増えていない場合は運営へ連絡するよう案内してください。二重に購入し直さないでください。
